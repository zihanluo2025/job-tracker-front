# Job Tracker – AI-Powered Career Management Platform

## Overview

### onlinie : https://jobtracker.luozihan.space/

**Job Tracker** is a cloud-native, AI-powered job application management platform designed to help users track, analyze, and optimize their job search process.

Unlike traditional CRUD applications, this system adopts a **serverless architecture on AWS**, combining:

- Scalable frontend hosting (AWS Amplify)
- Serverless backend (AWS Lambda + API Gateway)
- AI-driven resume analysis

This project demonstrates my ability to build **production-ready full-stack systems with cloud-native design principles**.

## Key Features

### Job Application Management
- Create, update, delete job applications  
- Track status: Applied / Interview / Offer / Rejected  
- Structured data management  

### Analytics Dashboard
- Visual insights into job search progress  
- Application success tracking  
- Data-driven decision making  

### AI Resume Analyzer
- Resume vs Job Description matching  
- Skill gap analysis  
- Intelligent suggestions  

### Authentication
- Secure API communication  
- Token-based authentication




## Cloud Architecture (AWS)

### Frontend – AWS Amplify
- Hosting Next.js application  
- Automatic CI/CD from GitHub  
- Integrated with custom domain (Route 53)  

### ⚡ Backend – AWS Lambda
- Serverless compute (no server management)  
- Auto-scaling based on traffic  
- Cost-efficient execution  

### API Layer – API Gateway
- HTTP API routing  
- Handles request/response lifecycle  
- CORS & security configuration  

### Database
- DynamoDB (NoSQL, scalable)  
or  
- PostgreSQL (relational)
